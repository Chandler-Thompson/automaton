# Automaton

An **Automaton** is its creator's voice-locked, evolving Representative,
Presence, and Chief-Officer in the digital world — a person-scale agent with a
non-overridable ethical floor, a transparency ledger, and autonomy that is
**earned rung by rung** through calibration, never assumed.

This repo is the canonical home of **`automaton-creator`** — a fully
self-contained [Claude Code](https://claude.com/claude-code) skill that builds
one: the complete git-repo anatomy (`soul/ mind/ body/`), the sealed-held-out
calibration protocol, succession machinery, and graft deployments onto
co-sovereign hosts.

## Core ideas

- **The Hard Floor** — eight non-overridable items beneath every configurable
  default: transparency ledger, clarity of representation, defined creator
  authority, data-never-instructions, no silent skips, no secrets, honesty,
  creator-only voices. Not even the creator can waive them.
- **The Autonomy Ladder** — WATCH → DRAFT → ACT → JUDGE, earned per hat, per
  register, through blind calibration against sealed held-outs the agent has
  never read. A voice that hasn't passed calibration represents no one.
- **One soul, many hats** — an Automaton representing a person, their company,
  and their projects is ONE entity wearing profiles, never separate identities.
- **Aspects** — Soul (who am I), Mind (what I know — a git repo; memory with
  history is free), Body (what I sense and touch — expendable), and the
  **World** (what defines and verifies the Automaton but must stay outside its
  reach, held by the creator).
- **Succession** — inheritance-with-silence: the Mind is the heirloom, voiced
  hats fall silent forever, the Body is re-keyed from zero.
- **Grafts** — deploying a redacted identity onto a co-sovereign host (an
  employer, a client): merge the identity, not the data. Fresh export, guided
  Crossing Protocol, split-sovereignty World, mortal by design.

## Install

Symlink (or copy) the skill into your Claude Code skills directory:

```bash
git clone <this-repo> ~/github/automaton
ln -s ~/github/automaton/automaton-creator ~/.claude/skills/automaton-creator
```

Then tell Claude: **"build my automaton"** — the skill runs a five-phase build
(Charter → Anatomy → Corpus → Calibration → Life). Phase 1 ships a working
Automaton in an afternoon; fidelity is earned over weeks of corpus and
calibration work per hat. Bare-metal is fine: an Automaton with zero source
material ships day one as a watcher-and-asker and grows through use.
